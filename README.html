DUNE STRIKE

Free, fast, low-bandwidth multiplayer FPS for LAN and small online servers.

Features

  • Push-to-talk voice chat with simultaneous speakers and an on-screen VU meter.
  • Hijabi player skins for both teams.
  • Classic arena modes, bots, demo recording and a built-in map editor.
  • Runs on Windows, Linux and Apple Silicon macOS.

Quick start

Linux / macOS: unpack the archive and run:

./dunestrike.sh

Windows: unzip the archive and run dunestrike.bat.

LAN server

./dunestrike-server.sh -n"Dune Strike LAN" -c10

Join from another machine:

connect 192.168.1.10 28763

Voice chat

Voice is enabled by default. Hold X to talk and press F9 to toggle voice chat.

Build from source

cd source/enet
./configure --enable-shared=no --enable-static=yes
make -j4
cd ../src
make -j4 client_install server_install
