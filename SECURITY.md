# Security policy

If you find a security problem in Dune Strike — in the client, the server, the
network protocol or the build/release tooling — please report it privately.

Use GitHub's private vulnerability reporting:

<https://github.com/aminghaseminia/dunestrike/security/advisories/new>

Please include:

- the affected version or commit,
- steps to reproduce,
- whether the issue affects clients, servers or both,
- any proof-of-concept files or logs (redact personal data).

Do not open a public issue for an unpatched vulnerability. You will get an
acknowledgement as soon as possible, and credit in the release notes if you
want it.
