License and origin
==================

Dune Strike is an altered distribution of the AssaultCube codebase. AssaultCube
itself is mainly based on the Cube game/engine and uses the same zlib-style
license. See README_CUBEENGINE.txt.

The original Dune Strike additions (the Dune Strike name, loading screen/icon,
hijabi player skins, push-to-talk voice chat and the release tooling) are
distributed under the same zlib-style terms.

Dune Strike contains code from pCube (Cube pro mod), Sauerbraten (Cube
successor) and other sources. Their notices are kept below and in the
per-component license files.

See CREDITS.md at the repository root for the full origin and contributor
summary.

===========

The AssaultCube project and its contributors (2004–present) produced the
codebase and most of the assets this distribution is based on. Their original
credits are preserved in the in-game About menu, in docs/package_copyrights.txt
and in the license.txt files shipped with the asset packages.

Cheat Protection
================

The cheat protection described in README_CUBEENGINE.txt is not used in Dune
Strike. Binaries compiled from source are compatible with the original
binaries. This means the client can be modified and recompiled for other
platforms, but it also means a modified client can be used to cheat.

You MUST NOT connect to servers that are not yours with a modified client that
contains gameplay changes which were not made for platform compatibility or to
fix bugs. This would be cheating. Thank you for supporting fair play.
